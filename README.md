# Real Estate Client Presentation Hub & Mockup Suite

A client presentation hub featuring 5 real estate web concepts accessible from a single master hub with an instant dropdown switcher, responsive device simulator (Desktop, Tablet, Mobile), and full multi-page architectures (25 total pages).

---

## 🌟 The 5 Real Estate Concepts

1. **Poperty (`designs/design1/`)**
   - **Style:** Monochrome Editorial & Architectural Luxury
   - **Pages:** Home (`index.html`), Curated Properties (`properties.html`), Studio Manifesto (`about.html`), Private Viewing (`contact.html`)

2. **Spaciaz (`designs/design2/`)**
   - **Style:** Commercial Developer & Institutional Capital Syndicate
   - **Pages:** Home (`index.html`), Landmark Assets (`projects.html`), Institutional Services Bento Grid (`services.html`), 40-Year Legacy (`about.html`), Offering Memorandum Desk (`contact.html`)

3. **Realnest (`designs/design3/`)**
   - **Style:** Editorial Serif Buy, Rent & Mortgage Hub
   - **Pages:** Home (`index.html`), Buy vs Rent Listings (`listings.html`), Global City Hubs (`cities.html`), Family Stories (`about.html`), Direct Concierge (`contact.html`)

4. **Aangan • आँगन (`designs/design4/`)**
   - **Style:** Ultra-Luxury Indian Heritage & Sky Mansions
   - **Features:** Royal Emerald & Gold aesthetic, ₹ Crores pricing, MahaRERA/HRERA/KRERA verification, 100% Vastu compliance, live EMI & On-Road cost calculator.
   - **Pages:** Home (`index.html`), Landmark Residences (`residences.html`), The Imperial Club Amenities (`amenities.html`), NRI Wealth & Repatriation Gateway (`nri-desk.html`), Private Client Concierge (`contact.html`)

5. **GrihaDirect • गृहडायरेक्ट (`designs/design5/`)**
   - **Style:** Smart Indian PropTech (0% Brokerage)
   - **Features:** Direct developer inventory (Godrej, DLF, Prestige, Lodha, Sobha, Joyville), dynamic commission savings slider, state-by-state stamp duty calculator, free AC cab visit scheduling, and WhatsApp direct inquiry.
   - **Pages:** Home (`index.html`), Verified Projects (`projects.html`), 0% Brokerage vs 2% Comparison (`compare.html`), All-Inclusive On-Road Cost Calculator (`cost-calc.html`), Post Free Property Desk (`contact.html`)

## 🚀 How to Run Locally

```bash
# Clone the repository
git clone https://github.com/nirbhaysagar/realestatedesign.git
cd realestatedesign

# Start a local preview server
python3 -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080) in your browser to view the client presentation hub.
